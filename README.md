# California-High-School-Dashboard
Hello and welcome! 

This dashboard is a personal project designed to visualize trends in California Public High Schools. Rest assured, it does not violate FERPA guidelines—no student-specific records are used. All data is sourced from the California Department of Education.

This Version includes my PyTorch model code. Upon creating the model and referring back to the Dept. of Education data records, more information needs to be collected for the creation of a proper ML model.

Hope this proves helpful,

- Arthur


Pipeline: CA Dept. of Ed → Python → Pandas + SQL + Pytorch → CSV/Google Sheets
